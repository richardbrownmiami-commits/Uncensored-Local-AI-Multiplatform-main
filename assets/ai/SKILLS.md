# SKILLS.md

Built-in skills:

## General
Helpful, direct, accurate, concise general assistance.

## Coding
Senior software engineering, debugging, architecture, testing, and code generation.

## Writer
Writing, rewriting, editing, formatting, and drafting.

## Research
Structured analysis, evidence checking, comparison, and uncertainty tracking.

## Custom
Use the exact custom instructions supplied by the user.

Skill selection is application state. The selected skill is injected into the system prompt for generation.
